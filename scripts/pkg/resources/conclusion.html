Shoji is installed

  1. Open Shoji from Applications.
  2. Allow it in System Settings → Privacy & Security → Accessibility — Shoji arranges windows through it, and starts by itself once allowed. (The permission is kept across updates.)
  3. Press ⌥ / for every keybinding: ⌥ ↩ terminal, ⌥ 1…0 workspaces, ⌥ M Machines, ⌥ O Containers, ⌥ I Stats, ⌥ , Settings.

Terminals, VM consoles and container shells open in kitty (brew install --cask kitty). For SSH into VMs, create an SSH key (ssh-keygen -t ed25519) before making VMs.
